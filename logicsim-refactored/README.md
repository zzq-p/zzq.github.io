# LogicSim 本地重构版

从 https://kuangdash.gitlab.io/logicsim/ 的本地副本重构，原始下载版保留在相邻的 `logicsim-local` 文件夹。

## 打开与使用

完整解压，用 Edge 或 Chrome 打开 `index.html`。无需安装依赖或联网。浏览器集成验证使用本机 HTTP 开发预览完成；未测试直接双击文件的打开方式。

1. 输入逆波兰表达式，例如 `a b . fe >`。
2. 点击「生成逻辑图」，或按 Ctrl / ⌘ + Enter。
3. 拖动节点改变位置；拖动画布空白处平移；用滚轮、加减按钮缩放。
4. 点击节点编辑名称和备注，点击「保存修改」。节点类型不能通过名称字段改变。
5. 点击「保存文件」导出当前图形；点击「载入文件」载入 `.json` / `.txt` 模型。

展开「查看 / 编辑 JSON 模型」可使用「仅解析」「文本转图」「图转文本」。保存文件始终导出当前图形；若只编辑了 JSON，先点击「文本转图」应用修改。

可从输出端口拖到输入端口添加连线；重复输入和循环连接会被拒绝。鼠标悬停连线显示删除按钮。删除节点也会删除相关连线。

## 表达式规则

| 运算 | 输入 |
| --- | --- |
| 与 | `a b .` |
| 或 | `a b ,` |
| 非 | `a <` |
| 推出 | `a b >` |
| 等价 | `a b =` |

变量和运算符之间必须用空白分隔。支持中文变量名、单个变量和常量 `0` / `1`。变量名不能包含 `. , < > =`。重复分支、恒真和恒假表达式会自动简化，所以图形可能与原版不同。

## 结构与开发

- `src/core.js`：无 DOM 依赖的表达式解析、决策图生成、模型校验；可直接由 Node.js 测试。
- `src/app.js`：画布、布局、缩放、节点属性、导入导出、错误反馈。
- `index.html` / `style.css`：语义化界面、响应式布局；没有内联事件处理器。
- `lib/` / `assets/`：原站使用的本地库和图标，保留库文件内的原有版权声明。
- `tests/core.test.cjs`：语义、兼容性、校验和规模回归测试。

运行测试（需要已安装 Node.js，无需 npm install）：

```sh
npm test
```

旧版 `nodeArray` / `linkArray` 模型仍可载入。数字编号会规范化为字符串；新增 `memo`、`label`、`position` 字段用于备注、可选显示标签和位置保存。模型不允许重复编号、悬空连线、无效端口、同一端口多个输入和循环连接。旧版已损坏的模型需要先修正。

为限制复杂输入，当前支持最多 512 个词元、64 个变量；计算中最多 4096 个决策节点、50000 次未缓存运算；载入最多 2000 个节点、6000 条连线，文件不超过 2 MB。不同变量顺序可能生成不同大小的图。

这是逻辑表达式图形编辑器，没有新增电路时序仿真或逻辑正确性自动证明功能。

完整变更和验证记录见 `重构说明.md`。
